# Quack

A small Minecraft mod for **Minecraft 1.21.1** using **NeoForge**.

## Features

- Adds a rubber duck that plays a quack sound when used.
- Lets you turn the chat message on or off with the server configuration option `show_quack_message`.
- Adds the duck to the **Tools & Utilities** creative tab.
- Includes a crafting recipe using dried kelp and yellow dye.
- Includes English and Russian translations.

## Building from source

1. Install a Java version supported by the project’s Gradle and Minecraft versions.
2. Open a terminal in the project directory.
3. Run the Gradle build:

   - Windows: `\.gradlew.bat build`
   - Linux/macOS: `./gradlew build`

The built mod JAR will be in `build/libs/`.

## Development

This project uses NeoForge MDK/NeoGradle. See the [NeoForge documentation](https://docs.neoforged.net/) for development details.
